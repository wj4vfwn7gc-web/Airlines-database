Airline Passenger Dashboard
Turning Passenger Data into Meaningful Insights
The Airline Passenger Dashboard is a data visualization project designed to analyze passenger satisfaction, customer types, flight distances, and arrival delays. It uses key performance indicators (KPIs), interactive filters, and charts to present important information in a simple and understandable way.
📊 1. Key Performance Indicators (KPIs)
The dashboard displays four important metrics:
✈️ Average Flight Distance: 714.12
🕒 Average Arrival Delay: 15.48
👤 Average Passenger Age: 30.35
🧾 Passenger Records: 23.78K
These indicators provide a quick overview of passenger demographics, flight distance, and arrival delays.
🎛️ 2. Dashboard Filters
The dashboard contains two filters that allow users to explore different passenger groups.
Gender: Female and Male
Customer Type: First-time and Returning
These filters help users compare passenger groups and observe how the displayed metrics change when different options are selected.

💡 4. Key Insights
Based on the dashboard, the following observations can be made:
Passenger Satisfaction: Neutral or dissatisfied passengers represent approximately 76.03% of the displayed records.
Average Age: The average passenger age is 30.35 years.
Flight Distance: The displayed average flight distance is 714.12 units.
Arrival Delay: The displayed average arrival delay is 15.48 units.
Travel Class: Economy appears to have the highest average arrival delay, while Business appears to have the lowest.
Flight Distance Distribution: The charts show more records at shorter distances, with counts generally decreasing at longer distances.
These observations should be verified against the original dataset before being used for business decisions.
